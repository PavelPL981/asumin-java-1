# Java: курс с нуля

Учебный курс Андрея Сумина по Java (на платформе Stepik), предназначенный для изучения следующих тем:
- базовый синтаксис,
- объектно-ориентированное программирование,
- исключения,
- JUnit-тестирование,
- collections,
- generics,
- многопоточность,
- Stream API,
- IO

## Description

Данный учебный проект создан в рамках самостоятельного изучения Java по ходу прохождения курса.  

Основные цели:

- освоение синтаксиса Java
- работа с базовыми структурами данных
- практика ООП
- развитие навыков проектирования кода
- закрепление на практике тем, изучаемых на курсе

## Technologies

- Java 17+
- IntelliJ IDEA
- Git / GitHub
